# Xendit WHMCS Payment Gateway Module

Xendit WHMCS Payment Gateway Module by SamudraDev is a commercial WHMCS payment module for businesses, hosting providers, agencies, SaaS companies, and Indonesian merchants that want to accept payments through Xendit directly from WHMCS invoices.

This module connects WHMCS invoice payments with Xendit using the official Xendit API. It is built for WHMCS users who need a working Xendit payment gateway integration for client billing, automated invoice payments, and payment confirmation through Xendit webhooks.

## WHMCS Xendit Integration

Xendit no longer provides an official WHMCS payment gateway module for direct WHMCS integration. This SamudraDev module solves that gap by allowing WHMCS installations to continue accepting payments through Xendit using official API-based invoice creation and webhook callbacks.

The module does not use unofficial payment scraping, browser automation, or unreliable checkout workarounds. Payments are created through the Xendit Invoice API and confirmed through secure callback processing inside WHMCS.

## How It Works

1. A customer opens an unpaid WHMCS invoice.
2. The customer selects Xendit as the payment method.
3. The module creates a Xendit invoice using the official Xendit API.
4. The customer completes payment on the Xendit hosted payment page.
5. Xendit sends a webhook callback to WHMCS.
6. WHMCS automatically marks the invoice as paid after successful verification.
